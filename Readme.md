# Satellite Data Provenance & Earth Observation Repository

**Team:** SRNS  
**Course:** DBMS Project — Semester 5

## Overview

This project implements a database for storing and managing **satellite data, Earth observation records, data provenance, and related metadata**.

The system uses a relational database to organize satellite observations, acquisition information, processing details, ground station records, and provenance relationships.

## Technologies

- MySQL
- MongoDB
- SQL
- GitHub

## Database

The project includes database schemas and sample data for storing satellite and Earth observation information. SQL scripts are used to create and populate the relational database, while MongoDB is used for document-based observation and metadata storage.
